# sinclair-zx-spectrum-ula

The video engine every ZX Spectrum-family ULA wraps.

| Crate | Registry |
|---|---|
| [`emu198x-sinclair-zx-spectrum-ula`](crates/emu198x-sinclair-zx-spectrum-ula) | [crates.io](https://crates.io/crates/emu198x-sinclair-zx-spectrum-ula) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Ferranti 6C001E, Sinclair 7K010E, Amstrad 40077, Timex SCLD, Pentagon and Scorpion ULAs.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
